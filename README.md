# WORLD HUB — starter website

A responsive black-and-gold global discovery portal.

## Included
- Responsive landing page
- English / Kurdish interface toggle
- Live local clock
- Country lookup using the public REST Countries API
- Quick web search
- Navigation sections for global discovery, tools, world and vision

## Publish with GitHub + Netlify
1. Create a new GitHub repository named `world-hub`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In Netlify, choose **Add new site → Import an existing project**.
4. Connect GitHub and select `world-hub`.
5. Leave build command empty and publish directory as `.` then deploy.

This is the first visual version. Weather forecasts, live news, translation, AI services, film catalogs and map features need trusted data providers / APIs and (for some services) API keys. Do not publish copyrighted films or TV streams without distribution permission.
